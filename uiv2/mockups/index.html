Design System Highlights

Collapsible Sidebar
Hierarchische Navigation mit Labels, Sections und Badges. Minimierbar auf 72px Icon-only Modus.
Command Palette
Cmd+K Power-User Interface: Navigation, Suche und Aktionen. Nach Vorbild von Linear und Notion.
Indigo Brand Identity
Indigo #6366F1 als Primary, Zinc-basierte Neutrals. Konsistentes Farbsystem ueber alle 15 Screens.
Bento Grid Dashboard
Metriken, Charts und Activity Feed in einem modernen Bento-Grid Layout mit Animationen.
Micro-Interactions
Spring Animations, Chart Reveal, Toast Stacking, Skeleton Loading fuer ein polished Erlebnis.
Inter 15px Typography
15px Base statt 12px. Modulare Type Scale mit Inter Font fuer optimale Lesbarkeit in allen Views.
