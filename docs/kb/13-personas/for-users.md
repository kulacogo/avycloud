# AvyCloud für Endanwender

Willkommen. AvyCloud ist deine Multi-Channel-Zentrale: ein Produkt erfassen, einmal pflegen, überall verkaufen — auf eBay, Kaufland und (bald) weiteren Marktplätzen.

## Was du in AvyCloud machst

| Aufgabe | UI-Bereich | Doku |
|---------|-----------|------|
| Neue Produkte mit KI erfassen | **Erfassen** | [05-pages/capture.md](../05-pages/capture.md) |
| Produkte verwalten, bearbeiten, Preise setzen | **Inventar**, **Stammdaten** | [05-pages/inventory.md](../05-pages/inventory.md), [05-pages/product-sheet.md](../05-pages/product-sheet.md) |
| Bestellungen sehen und abwickeln | **Bestellungen** | [05-pages/orders.md](../05-pages/orders.md) |
| Versandlabels erstellen | **Versand** | [05-pages/shipping.md](../05-pages/shipping.md) |
| Retouren bearbeiten | **Retouren** | [05-pages/returns.md](../05-pages/returns.md) |
| Rechnungen verwalten | **Rechnungen** | [05-pages/invoices.md](../05-pages/invoices.md) |
| Lager und BINs organisieren | **Lager** | [05-pages/warehouse.md](../05-pages/warehouse.md) |
| Marktplatz-Listings überwachen | **Marketplace** | [05-pages/marketplace-listings.md](../05-pages/marketplace-listings.md) |
| Mit der KI sprechen (Chat) | **Chat im Produkt-Datenblatt** | [05-pages/chat.md](../05-pages/chat.md) |

## Tipps

- **Erfassen ist KI-gestützt**: lade Bilder hoch, AvyCloud erkennt das Produkt, schlägt Titel/Kategorie/Aspekte vor.
- **Datenblatt-Chat**: wenn dir Daten fehlen, frag die KI direkt im Datenblatt.
- **Hilfe-Button** (oben rechts in der App): öffnet diese KB im Drawer.
