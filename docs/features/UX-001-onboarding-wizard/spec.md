## Problem Statement

AvyCloud has no guided onboarding flow. Users must figure out marketplace connections, product imports, and feature discovery on their own. Competitors like Sellbrite and Billbee offer wizard-guided onboarding that gets sellers live within minutes/hours. Channable's progressive disclosure pattern introduces complex features gradually.

---

## User Story

As a new AvyCloud user, I want a step-by-step setup wizard that guides me through connecting my marketplaces, importing my first products, and creating my first listing, so that I can start selling quickly without reading documentation.

---

## Requirements

| ID | Priority | Requirement |
|----|----------|-------------|
| FR-1 | MUST | Guide through marketplace account connection (eBay, Kaufland) |
| FR-2 | MUST | Guide through first product import/creation |
| FR-3 | MUST | Introduce key features progressively (identify, improve, list) |
| FR-4 | SHOULD | Use AvyCloud's AI identify as the "wow moment" during onboarding |
| FR-5 | SHOULD | Show progress indicator (steps completed / total) |
| FR-6 | SHOULD | Be skippable for experienced users |
| FR-7 | MAY | Include interactive tooltips for feature discovery after initial setup |

---

## Competitive Benchmarks

| Competitor | Capability | Gap vs. AvyCloud |
|------------|-----------|------------------|
| **Sellbrite** | Wizard-guided onboarding, marketplace connection in minutes | AvyCloud has no onboarding flow |
| **Billbee** | Step-by-step setup wizard, gets sellers live within hours | AvyCloud has no onboarding flow |
| **Channable** | Progressive disclosure, introduces complex features gradually | AvyCloud shows all features at once |
| **Nifty AI** | "Photo to listing in 30 seconds" as instant wow moment | AvyCloud's AI features are discoverable but not guided |
